# Astrobiology repos

A list of my repositores in astrobiology.


## [Habitable dot](https://github.com/ferdesmello/habitable-dot)

A coupled geophysical and atmospheric model to estimate the evolution of the circumstellar habitable zone in function of many parameters.

## [Exoplanets in the galaxy 3d](https://github.com/ferdesmello/exoplanets-in-the-galaxy-3d)

A 3D interactive map of the exoplanets discovered in our Galaxy.

## [Drake Metaculus](https://github.com/ferdesmello/drake-metaculus)

Code to calculate the distribution of the possible number of detectable alien civilizations in our Galaxy using the Drake equation and Metaculus predictions.

## [Drakelicit](https://github.com/ferdesmello/drakelicit)

Code for an expert elicitation website made for the Drake equation but flexible enough to be used for other elicitations.

## [Drakelicit online](https://github.com/ferdesmello/drakelicit-online)

Code for a website to survey users over the Drake equation using probability distributions.
