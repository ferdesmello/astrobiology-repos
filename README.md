# Astrobiology repos

A list of my repositories in astrobiology.

## [Habitable dot](https://github.com/ferdesmello/habitable-dot)

A coupled geophysical and atmospheric model to estimate the evolution of the circumstellar habitable zone in function of many parameters.

[![Interactive visualization](https://github.com/ferdesmello/habitable-dot/blob/main/figures/Sun_Earth_CHZ_01.png)](https://github.com/ferdesmello/habitable-dot)

## [Exoplanets in the galaxy 3d](https://github.com/ferdesmello/exoplanets-in-the-galaxy-3d)

A 3D interactive map of the exoplanets discovered in our Galaxy.

[![Interactive visualization](https://github.com/ferdesmello/exoplanets-in-the-galaxy-3d/blob/main/images/Visualization.jpeg)](https://ferdesmello.github.io/exoplanets-in-the-galaxy-3d)

## [The Great Filter Toy-Model](https://github.com/ferdesmello/the-great-filter-toy-model)

A small interactive toy model for exploring how evidence about extraterrestrial life changes where the Great Filter is most likely to be.

[![Interactive visualization](https://github.com/ferdesmello/the-great-filter-toy-model/blob/main/figures/top_GUI.png)](https://github.com/ferdesmello/the-great-filter-toy-model)

## [Drake Metaculus](https://github.com/ferdesmello/drake-metaculus)

Code to calculate the distribution of the possible number of detectable alien civilizations in our Galaxy using the Drake equation and Metaculus predictions.

[![Interactive visualization](https://github.com/ferdesmello/drake-metaculus/blob/main/figures/Drake_by_Metaculus_PDF_local_CSVs.png)](https://github.com/ferdesmello/drake-metaculus)

## [Drakelicit](https://github.com/ferdesmello/drakelicit)

Code for an expert elicitation website made for the Drake equation but flexible enough to be used for other elicitations.

[![Interactive visualization](https://github.com/ferdesmello/drakelicit/blob/main/figures/drake_survey_N.png)](https://github.com/ferdesmello/drakelicit)

## [Drakelicit online](https://github.com/ferdesmello/drakelicit-online)

Code for a website to survey users over the Drake equation using probability distributions.

[![Interactive visualization](https://github.com/ferdesmello/drakelicit-online/blob/main/figures/drake_survey_N.png)](https://github.com/ferdesmello/drakelicit-online)
